# KNN Regression Practical

## Description

This practical demonstrates K-Nearest Neighbors (KNN) Regression using
Python and Scikit-learn. It covers preparing data, scaling features,
training a regression model, and evaluating its predictions.

## Objective

To understand and implement the KNN Regression algorithm for predicting
a continuous target value from input features.

## Technologies Used

-   Python
-   Jupyter Notebook
-   Pandas
-   NumPy
-   Matplotlib / Seaborn (if used in the notebook)
-   Scikit-learn

## Files

-   `KNN Regression (3).ipynb` --- Notebook containing the practical.
-   Dataset CSV --- Upload the dataset used by the notebook, if
    required, and keep its filename/path consistent with the code.

## How to Run

1.  Clone or download this repository.

2.  Install the required libraries:

    ``` bash
    pip install pandas numpy scikit-learn matplotlib seaborn jupyter
    ```

3.  Keep the dataset in the location expected by the notebook.

4.  Open `KNN Regression (3).ipynb` in Jupyter Notebook, VS Code, or
    Google Colab.

5.  Run the cells in order.
